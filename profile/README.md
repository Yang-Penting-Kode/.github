## 🤝 Cara Berkontribusi

Kami sangat terbuka untuk kontribusi dari siapa saja! Berikut langkah-langkahnya:

1. **Fork** repositori yang ingin kamu kontribusikan.
2. **Buat branch** baru untuk fitur atau perbaikan kamu (`git checkout -b feat/nama-fitur`).
3. **Commit** perubahan kamu dengan pesan yang jelas (`git commit -m "feat: tambahkan fitur X"`).
4. **Push** ke branch kamu (`git push origin feat/nama-fitur`).
5. Buka sebuah **Pull Request** dan jelaskan perubahan yang kamu buat.

Pastikan kamu sudah membaca [panduan berkontribusi](CONTRIBUTING.md) sebelum memulai.
